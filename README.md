# CV — GitHub Pages

Static CV website for GitHub Pages.

## Files
- `index.html` — CV
- `script.js` — optional print helper
- `assets/` — put CV images here

## Publish
1. Create a GitHub repository (for example `cv`).
2. Copy/push all files in this folder to the `main` branch.
3. GitHub → repository → Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`, folder: `/ (root)`.
6. Save and wait for the Pages deployment.

The CV entry point is the root `index.html`.
